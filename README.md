# 个人博客模板
欢迎来到我的个人博客

博客查看在posts下

使用说明：
1. 仓库名是 `Qin-ying.github.io`（仓库在 Chen-xue-qin 帐户下）。注意：要发布为“用户/组织主页”需要仓库名为 `Chen-xue-qin.github.io`；当前为项目站点，访问路径将是 `https://Chen-xue-qin.github.io/Qin-ying.github.io` 或者需要在 Settings→Pages 中设置自定义发布位置。
2. 等待几分钟（通常 1-5 分钟）即可访问站点，如果没自动发布请到仓库 Settings → Pages 检查。
3. 写新文章：在 `_posts` 下新建 `YYYY-MM-DD-标题.md`，在文件顶部写 front-matter（title, date, layout），然后写正文并提交。

示例新文章文件内容（可复制粘贴到 `_posts/2026-07-28-我的第一篇.md`）：

```
---
layout: default
title: 我的第一篇文章
date: 2026-07-28 09:00:00 +0800
---

# 我的第一篇文章

欢迎阅读！这是用 Markdown 写的内容。
```

在 GitHub 网站上操作：Add file → Create new file → 在名称处填 `_posts/2026-07-28-我的第一篇.md` → 粘贴内容 → Commit。
